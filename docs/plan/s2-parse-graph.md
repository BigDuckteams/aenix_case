# S2. Разбор Java и построение графа

**Часы:** H3–14 · **Трек:** A (engine) · **Веха:** M1 (вход) · **Требования:** FR-02, FR-03, FR-04

## Цель

Превратить Java-текст в семантическую модель, граф структуры и блок-схемы методов со стабильными ID и точными диапазонами. Покрыть весь обязательный и бонусный scope (record, enum, дженерики, лямбды, Stream).

## Зависимости

S0.7 (обёртка tree-sitter), S1.1 (схемы), S1.3/S1.6 (корпус).

## Задачи

| ID | Задача | Ч | Результат и тесты |
|---|---|---|---|
| S2.1 | `engine/java/ts.py`, `cst.py`: парсер, обход, поиск `ERROR`/`MISSING` → `SyntaxIssue`; перевод байтовых смещений в `{line, col}` (UTF-16, с 1) — `graph/ranges.py` | 1 | Тесты: кириллица в строках и комментариях, CRLF, табы, эмодзи; диапазоны совпадают с ожиданием Monaco |
| S2.2 | Декларации (`engine/java/symbols.py`): пакеты, импорты, классы, интерфейсы, `record` (компоненты, компактный конструктор), `enum` (константы с телами), вложенные/локальные/анонимные типы, дженерик-параметры и границы, поля, методы (varargs), конструкторы, блоки инициализации, `throws`, аннотации | 2 | Фикстуры `scope/01-*`, `b1-*`, `b2-*`: дерево типов и членов совпадает с ожидаемым JSON |

| S2.7 | Наложения и составные выражения: бейджи «ввод»/«вывод»/«ошибка» (`Scanner`, `System.in`, `System.out/err`, `printf`), `call` (вызов метода проекта → ребро в схему вызываемого), блок «Лямбда» (вложенная карточка), конвейер Stream (этапы с типами), анонимные и локальные типы, `local_type` | 1,5 | Фикстуры `scope/02-*`, `b3-*`, `b4-*`; снапшоты бейджей |

## Артефакты

- `backend/engine/java/*`, `backend/engine/graph/*` + тесты и снапшоты.
- Фикстуры scope, ожидаемые виды блоков.

## Критерии выхода

- [ ] На всём корпусе (кроме `broken`/`out-of-scope`) разбор без ошибок (I1).
- [ ] Для всех методов `demo-orders` построена схема, I3 зелёный: ни один оператор не потерян.
- [ ] Разбор и построение графа `demo-orders` ≤ 300 мс.
- [ ] Строки таблицы scope разделов 1–4 и бонуса дают ожидаемые виды блоков; на `broken` разбор не падает и возвращает ошибки с позициями.
- [ ] `locate(file, line, col)` возвращает узел; ID стабильны.
